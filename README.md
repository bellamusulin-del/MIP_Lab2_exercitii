# MIP_Lab2_exercitii
Aplicatia va afisa o fereastra (poate sa fie si consola) care accepta introducerea unei valori de tip intreg intre 1 si 10. 
Dupa introducerea valorii, aplicatia va genera numarul respectiv de fire de executie si le va porni. 
Fiecare fir de executie va rula pentru 10 secunde.
La pornirea fiecarui fir acesta va afisa un text de genul "Thread X has started.", unde X este ID-ul firului de executie.
La terminare, fiecare fir de executie va scrie "Thread X has finished Running.", unde X este ID-ul firului de executie.
Optional:
Dupa pornirea firului, utilizatorul poate introduce un id al unui fir pe care doreste sa il opreasca, iar aplicatia va opri acel fir de executie. 
Daca firul este oprit, acesta va afisa: "Thread X was cancelled.", unde X este ID-ul firului de executie.
